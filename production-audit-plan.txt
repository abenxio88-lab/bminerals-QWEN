======================================================================
STEP 2 — SECURITY HARDENING (.HTACCESS)
======================================================================
Implement production security best practices inside the root `.htaccess` file.
Ensure the following headers are fully active and tested:
• Content-Security-Policy (Strictest possible WITHOUT breaking external CDNs/Fonts)
• X-Content-Type-Options (Enforce 'nosniff')
• Referrer-Policy ('strict-origin-when-cross-origin')
• Permissions-Policy (Restrict unauthorized camera, microphone, geolocation hardware APIs)
• Cross-Origin-Opener-Policy & Cross-Origin-Resource-Policy
• Strict-Transport-Security (HSTS enforced for subdomains)
• X-Frame-Options (Enforce 'DENY' or 'SAMEORIGIN' against clickjacking)
* Note: Since this is an Apache/Hostinger target, use `.htaccess` instead of `vercel.json`.

STEP 5 — PERFORMANCE OPTIMIZATION
======================================================================
Optimize every layout asset to target 95+ performance scores:
• Convert images to WebP where possible without perceptible quality loss.
• Preload ONLY critical hero assets at the top of the viewport.
• Native lazy-load (`loading="lazy"`) all images below the fold.
• Compress and tree-shake JavaScript. Minify raw CSS and clean HTML output.
• Ensure Brotli/Gzip compression is running on Hostinger.
• Configure aggressive browser caching headers for static assets.
• Reduce render-blocking resources and ensure zero Cumulative Layout Shift (CLS).
